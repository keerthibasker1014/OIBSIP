# EDA on Retail Sales Data

## Project Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data to understand sales trends, customer demographics, product performance, and revenue patterns.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Dataset inspection
- Data types and missing values
- Descriptive statistics
- Monthly sales trends
- Quarterly sales trends
- Customer demographics
- Top 10 best-selling products
- Revenue by category
- Correlation heatmap
- Additional visualization

## Key Insights
The analysis provides insights into sales trends, customer behaviour, product performance, and category-wise revenue.

## Business Recommendations
1. Focus marketing efforts on high-performing customer segments.
2. Promote top-selling products and high-revenue categories.
3. Use sales trends to improve inventory planning and promotional activities.
